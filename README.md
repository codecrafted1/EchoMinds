EchoMind is an intelligent, dark-themed web chat interface designed to make human–AI interactions more natural and empathetic. Built using HTML, CSS, and JavaScript, it combines emotion recognition, voice-to-text, and text-to-speech to create a conversational experience that listens, feels, and responds like a real companion.

🔍 Key Features

Dark Modern UI: Clean, minimal, and fully responsive design for better focus and aesthetics.

Emotion Detection: Analyzes user messages using keyword-based sentiment mapping to identify emotions like joy, sadness, anger, fear, and surprise.

Voice-to-Text Input: Uses the browser’s SpeechRecognition API to let users talk naturally instead of typing.

Text-to-Speech Output: The chatbot can “speak” its responses aloud using SpeechSynthesis.

Local Storage Memory: Saves chat history locally so conversations persist across sessions.

Lightweight & Client-Side: No backend required — everything runs securely in the user’s browser.

⚙️ Tech Stack

Frontend: HTML, CSS, JavaScript

APIs: Web Speech API (for speech recognition & synthesis)

Storage: Browser LocalStorage
